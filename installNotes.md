1\. If moving site to new server, you must recompile. Make sure the latest version of Deno is installed ([https://github.com/denoland/deno/](https://github.com/denoland/deno/))

2\. Before rebuild, update appsettings.json with new path to **Deno.exe**

3\. After building and installing website, get the latest versions of [yt-dlp.exe](https://github.com/yt-dlp/yt-dlp) and [ffmpeg.exe](https://ffmpeg.org/download.html) and place in "\*siteroot\*\\tools". 

4\. Run site
